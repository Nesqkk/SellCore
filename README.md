# SellCore

Repositório principal do projeto **SellCore**.

## Estrutura

```text
SellCore/
├── backend/
├── frontend/
├── .gitignore
└── README.md
```

## Organização da equipe

- `frontend/` — desenvolvimento da interface e experiência do usuário.
- `backend/` — desenvolvimento da API, regras de negócio, banco de dados e serviços.

Cada parte do projeto pode ser desenvolvida separadamente, mantendo frontend e backend dentro do mesmo repositório.
